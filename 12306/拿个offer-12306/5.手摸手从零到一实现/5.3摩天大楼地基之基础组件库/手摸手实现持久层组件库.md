# 手摸手实现持久层组件库

## 组件地址
```xml
<dependency>
  <groupId>org.opengoofy.index12306</groupId>
  <artifactId>index12306-database-spring-boot-starter</artifactId>
  <version>${project.version}</version>
</dependency>
```

## 组件概述
该组件开发基于mybatis-plus框架，实现如下功能：

1. 封装通用分页组件。
2. 封装数据持久层基础属性+封装元数据处理器。
3. 封装分页工具转换器。
4. 封装自定义雪花算法。

```
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-boot-starter</artifactId>
</dependency>
```

## 组件功能

### 通用分页组件
定义 MySQL 分页插件配置，避免每个项目都需要重新定义。

```java
package org.opengoofy.index12306.framework.starter.database.config;

import com.baomidou.mybatisplus.annotation.DbType;
import com.baomidou.mybatisplus.core.incrementer.IdentifierGenerator;
import com.baomidou.mybatisplus.extension.plugins.MybatisPlusInterceptor;
import com.baomidou.mybatisplus.extension.plugins.inner.PaginationInnerInterceptor;
import org.opengoofy.index12306.framework.starter.database.handler.CustomIdGenerator;
import org.opengoofy.index12306.framework.starter.database.handler.MyMetaObjectHandler;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Primary;

/**
 * MybatisPlus 配置文件
 *
 * @公众号：马丁玩编程，回复：加群，添加马哥微信（备注：12306）获取项目资料
 */
public class MybatisPlusAutoConfiguration {

    /**
     * 分页插件
     */
    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        return interceptor;
    }
}
```

### 元数据处理器

前置信息：******实体基础属性->class BaseDO******

因为每个表都有公共的一些属性，比如创建时间、修改时间以及是否逻辑删除标识。为了避免每个实体上都重复定义，我们在持久层对象中抽象一个基础的 BaseDO 杜绝上述重复行为。

 *  * ```
     @Data
     public class BaseDO {
  
     /**
     
         * 创建时间
           */
           @TableField(fill = FieldFill.INSERT)
           private Date createTime;
  
        /**
     
         * 修改时间
           */
           @TableField(fill = FieldFill.INSERT_UPDATE)
        private Date updateTime;
     
        /**
     
         * 删除标志
           */
        @TableField(fill = FieldFill.INSERT)
        private Integer delFlag;
        }
  ```

MyBatisPlus 为我们提供了一种便利的方式为上述这些实体基础属性赋值，那就是元数据处理器。

可在数据新增或修改，再或者新增和修改时对元数据进行变更。

```java
/**
 * 元数据处理器
 */
public class MyMetaObjectHandler implements MetaObjectHandler {

    /**
     * 数据新增时填充
     * @param metaObject
     */
    @Override
    public void insertFill(MetaObject metaObject) {
        this.strictInsertFill(metaObject, "createTime", Date.class, new Date());
        this.strictInsertFill(metaObject, "updateTime", Date.class, new Date());
        this.strictInsertFill(metaObject, "delFlag", Integer.class, DelEnum.NORMAL.code());
    }

    /**
     * 数据修改时填充
     * @param metaObject
     */
    @Override
    public void updateFill(MetaObject metaObject) {
        this.strictInsertFill(metaObject, "updateTime", Date.class, new Date());
    }
}
```

### 分页转换器工具类：PageUtil

#### （1）位置

org.opengoofy.index12306.framework.starter.database.toolkit;

#### （2）作用

为什么需要这个分页转换器工具类，是将谁转换成谁？

在[手摸手实现规约组件模块](https://www.yuque.com/magestack/12306/mhds4epox1x2my7a#N6tob)介绍当中，详细说明了为什么会有自定义分页参数`PageRequest` 和 `PageResponse` 

作为防腐层，主要目的将业务逻辑层与底层持久层框架(MyBatis-Plus)解耦：

- **业务层**：只依赖于项目自定义的 `PageRequest` 和 `PageResponse`，**不直接依赖 MyBatis-Plus 的 API**

  ![image-20260220221854738](C:\Users\ZhouYan\AppData\Roaming\Typora\typora-user-images\image-20260220221854738.png)

- **持久层**：负责将 `PageRequest` 转换为 MyBatis-Plus 的 `Page`，执行查询后将 `IPage` 转换为 `PageResponse`

这种设计使得即使**更换底层 ORM 框架(如从 MyBatis-Plus 切换到 JPA)，******业务层代码**不需要修改。如上图所示，业务模块与持久层框架通过引入`PageRequest` 和 `PageResponse`发生解耦。

为了实现解耦，才需要在持久层组件库引入PageUtils这个分页转换器工具类，用于将业务层`PageRequest` 和 `PageResponse对象与持久层的Page和IPage之间进行转化。

所以大致可以揣测，Page~=PageRequest功能，IPage~=PageResponse

#### （3）内容

该工具类通过一系列静态方法实现分页对象的转换

1、**请求转换**：将 `PageRequest` 转换为 `Page` 对象

将前端发送的分页请求（跳转到第几页current+limit-->PageRequest ）转换为mybatis-plus持久层能识别的分页对象Page

### 自定义雪花算法
定义雪花算法类，并替换 MyBatisPlus 原有的雪花 ID 生成器。

```java
package org.opengoofy.index12306.framework.starter.database.handler;

import com.baomidou.mybatisplus.core.incrementer.IdentifierGenerator;
import org.opengoofy.index12306.framework.starter.distributedid.toolkit.SnowflakeIdUtil;

/**
 * 自定义雪花算法生成器
 *
 * @公众号：马丁玩编程，回复：加群，添加马哥微信（备注：12306）获取项目资料
 */
public class CustomIdGenerator implements IdentifierGenerator {

    @Override
    public Number nextId(Object entity) {
        return SnowflakeIdUtil.nextId();
    }
}
```



配置类中声明 `@Primary` 上述雪花算法生成器是主要的，不再使用默认的雪花 ID 生成器。

```java
package org.opengoofy.index12306.framework.starter.database.config;

import com.baomidou.mybatisplus.annotation.DbType;
import com.baomidou.mybatisplus.core.incrementer.IdentifierGenerator;
import com.baomidou.mybatisplus.extension.plugins.MybatisPlusInterceptor;
import com.baomidou.mybatisplus.extension.plugins.inner.PaginationInnerInterceptor;
import org.opengoofy.index12306.framework.starter.database.handler.CustomIdGenerator;
import org.opengoofy.index12306.framework.starter.database.handler.MyMetaObjectHandler;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Primary;

/**
 * MybatisPlus 配置文件
 *
 * @公众号：马丁玩编程，回复：加群，添加马哥微信（备注：12306）获取项目资料
 */
public class MybatisPlusAutoConfiguration {

    /**
     * 自定义雪花算法 ID 生成器
     */
    @Bean
    @Primary
    public IdentifierGenerator idGenerator() {
        return new CustomIdGenerator();
    }
}
```
